# Responsive E-Commerce Product Gallery

## Project Description
This project is a simple and responsive E-Commerce Product Gallery created using HTML and CSS. It displays different products in attractive cards with images, prices, categories, and hover effects.

## Features
- Responsive product grid layout
- CSS Grid using `auto-fit` and `minmax()`
- Minimum card width of 250px
- Real product images
- Product name and price
- Category labels
- Hover animation and image zoom effect
- Simple and user-friendly design

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code

## Responsive Layout
The product gallery automatically adjusts the number of columns according to the screen size. It uses CSS Grid without media queries for the product grid.

```css
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
```

## How to Run
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in any web browser.
4. Hover over the product cards to see the animation.
